# Исправление структуры колонок в Google Sheets

## Проблема
Колонка **"Командировочная надбавка"** находилась в неправильном месте — перед "Итого выручка" и "Фото чека", из-за чего данные записывались со смещением.

### ❌ Старая структура (НЕПРАВИЛЬНАЯ):
- A: Дата и время
- B: Номер терминала
- C: Менеджер
- D: Канал продаж
- E: Город
- F: Точка (название)
- G: Наличные
- H: Безналичные
- I: Кредит/Рассрочка
- J: Инкассация
- **K: Командировочная надбавка** ← БЫЛО ЗДЕСЬ (неправильно!)
- L: Итого выручка
- M: Фото чека
- N: Комментарий
- O: ID транзакции

### ✅ Правильная структура (после исправления):
- A: Дата и время
- B: Номер терминала
- C: Менеджер
- D: Канал продаж
- E: Город
- F: Точка (название)
- G: Наличные
- H: Безналичные
- I: Кредит/Рассрочка
- J: Инкассация
- K: Итого выручка
- L: Фото чека
- **M: Командировочная надбавка** ← ТЕПЕРЬ ЗДЕСЬ (после фото чека!)
- N: Комментарий
- O: ID транзакции

## Решение

### Способ 1: Автоматическое исправление (рекомендуется)

Запустите скрипт, который автоматически:
1. Прочитает все данные из таблицы
2. Переставит колонку "Командировочная надбавка" после "Фото чека" (колонка M)
3. Исправит сдвиг данных для всех записей
4. Перезапишет таблицу с правильной структурой

```bash
node scripts/fix_google_sheets_columns.js
```

**⚠️ ВАЖНО: Перед запуском рекомендуется создать резервную копию таблицы!**

### Способ 2: Ручное исправление

Если вы предпочитаете исправить вручную:

1. Откройте таблицу в Google Sheets
2. Найдите колонку с "Командировочная надбавка" (обычно K)
3. Вырежите всю колонку (Ctrl+X)
4. Вставьте её после колонки "Фото чека" (L) — станет колонкой M
5. Проверьте, что теперь:
   - K: Итого выручка
   - L: Фото чека
   - M: Командировочная надбавка
   - N: Комментарий
   - O: ID транзакции

## Проверка после исправления

После исправления проверьте несколько записей:
- Все колонки должны содержать правильные данные
- ID транзакции должен быть в колонке O
- Фото чека должно быть в колонке L
- Командировочная надбавка должна быть в колонке M

## Влияние на бота

После исправления таблицы бот будет корректно записывать все данные:
- Фото чека записывается в колонку L
- Командировочная надбавка записывается в колонку M
- Данные не смещаются

## Дополнительная информация

Командировочная надбавка — это поле для учета дополнительных расходов при работе в командировке (суточные, проживание и т.д.).
